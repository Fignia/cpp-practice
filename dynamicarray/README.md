# Dynamic Array

Practice project to understand dynamic memory allocation in C++.

## What it does
- Takes array size from user
- Allocates memory dynamically with `new`
- Fills array with user input
- Prints values and memory addresses
- Frees memory with `delete[]`

## Concepts covered
- Dynamic memory (`new` / `delete[]`)
- Null pointer check (`nullptr`)
- Early return pattern
- Pointer arithmetic and addresses
