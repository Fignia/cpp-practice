# Todo List

Practice project to understand `std::vector` in C++.

## What it does
- Add multiple tasks to the list
- Show all tasks with numbers
- Delete task by number
- Clear entire list
- Simple console menu

## Concepts covered
- `std::vector` — dynamic array
- `push_back`, `erase`, `clear`, `empty`
- Range-based for loop
- `getline` vs `cin`
- `cin.ignore()` — buffer management
- Splitting logic into functions
